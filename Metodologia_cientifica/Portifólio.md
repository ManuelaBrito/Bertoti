## Sobre mim ##

Sou estudante do curso de Banco de Dados na FATEC Jessen Vital (turma noturna, ingresso em 2025). Entrei no curso sem nenhuma experiência em programação e fui construindo a base com muita prática, principalmente em lógica e matemática, que eram meus maiores desafios.

Hoje meu foco é o desenvolvimento backend e o trabalho com bancos de dados, e os projetos do curso são onde mais aprendo:

- Atlaz4 / GeoRural (API): API em Java com Spring Boot integrada ao Oracle Spatial, com dados geográficos, versionamento do banco com Flyway e testes automatizados.
- devops-agent: aplicação em Spring Boot 3 / Java 17.
- Data lake na nuvem: pipeline de dados orquestrado com Apache Airflow na Oracle Cloud (OCI).
- Laboratório de Banco de Dados: montei meu próprio ambiente Oracle, em máquina virtual e em container, para praticar administração, arquitetura multitenant (CDB/PDB) e controle de transações.
- Em paralelo, trabalho como desenvolvedora backend na Kaffa. Lá uso Kotlin em um sistema de gestão de rede elétrica, e essa rotina me ensinou a trabalhar com código em equipe, code review e versionamento com Git.

Meu objetivo é entender o porquê das coisas, e não só fazer funcionar: como o banco executa uma consulta, o que o framework faz por baixo e como projetar sistemas que sejam fáceis de manter. Também participo de maratonas de programação e eventos técnicos para acelerar esse aprendizado.

## **2026 - 1º Semestre** ##

***Empresa parceira:*** IPEM - Instituto de Pesos e Medidas do Estado de São Paulo

***Nome do Projeto:*** IPEM CONTROL

<img width="900" height="200" alt="IPEM (600 x 200 px) (900 x 200 px)" src="https://github.com/user-attachments/assets/476687ba-2d7b-4d9b-88ba-2612e8b9b833" />

**Descrição do problema:**  O IPEM realiza o controle de abastecimento das viaturas da Regional de São José dos Campos por meio de registros manuais. Após cada abastecimento, os condutores anotam informações como quilometragem, quantidade de combustível, valor abastecido e identificação do responsável em pranchetas físicas mantidas dentro de cada veículo. Esse processo torna a consolidação e a análise das informações demoradas e suscetíveis a erros, além de dificultar o acompanhamento do consumo de combustível, a comparação do desempenho entre as viaturas e a identificação de possíveis inconsistências nos registros.

**Solução do problema:** Desenvolver um sistema web para digitalizar o processo de controle de abastecimento das viaturas. O sistema permitirá que os condutores registrem os abastecimentos de forma eletrônica, enquanto os gestores poderão validar as informações e acompanhar os dados por meio de relatórios analíticos. O IPEM CONTROL organizará os registros em uma base de dados estruturada, automatizando a conferência das informações, facilitando a consolidação mensal dos abastecimentos e proporcionando maior agilidade, transparência e eficiência na gestão da frota.

## 2026 - 2º Semestre

**Empresa parceira:** VISIONA

**Nome do Projeto:** GeoRural DataHub

<img width="1074" alt="GeoRural DataHub" src="https://github.com/user-attachments/assets/742050b7-d47e-4643-b9cc-ec2421e037af" />

**Descrição do problema:** Dados territoriais e ambientais de propriedades rurais chegam de diversas fontes, sem padronização, validação ou rastreabilidade. Isso dificulta garantir a qualidade dos registros, saber a origem de cada indicador e acompanhar a ingestão de novos dados.

**Solução do problema:** Desenvolvimento do GeoRural DataHub, uma plataforma web com Spring Boot no back-end e Vue.js no front-end. A solução centraliza o controle, validação e governança de dados territoriais em um banco de dados relacional Oracle, permitindo a gestão de lotes de ingestão, rastreabilidade completa (data lineage) de indicadores ambientais, controle de qualidade de registros rurais através de procedimentos em PL/SQL e visualização espacial interativa e reativa com suporte a dados em tempo real via WebSocket.
